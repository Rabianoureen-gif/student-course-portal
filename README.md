# Student Course Portal 🎓

A responsive and modern web-based course registration interface built using HTML5 and CSS3. 

## 📌 Features
- **Interactive UI:** Visually structured course cards with custom hover and focus effects.
- **Form Layout:** Clean and accessible inputs for student information, course selection, and term choices.
- **Responsive Design:** Optimized layout that ensures high visual clarity across modern display standards.

## 🛠️ Tech Stack
- **HTML5:** Semantic structural layout.
- **CSS3:** Custom styles, Flexbox layout, dynamic state transitions, and responsive design.
